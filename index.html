Government Primary School Pethgam Wagoora · Session 2026–27

1. Upload student result & attendance workbooks

Upload the result workbook, then select Import Excel Data. The importer reads the first worksheet by default and attempts to identify common student/marks column names. Review the preview before printing.

Privacy: files are processed in this browser and are not uploaded to a server by this page. Excel reading, QR and barcode generation require an internet connection to load the libraries.

2. Select student and review marksheet

Important: FA1–FA6, summative, co-curricular scores, student photo, APAAR ID, PEN and attendance are shown only when provided by the imported data. Missing information is marked “Not provided”; it is never guessed. Class/school ranks are not issued unless the imported cohort has comparable totals and rank calculation is possible.
Upload a workbook or select “Load Sania Preview Data” to render a marksheet.
